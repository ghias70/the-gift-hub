# The Gift Hub — website assets

Starter asset pack for the one-page ecommerce homepage mockup.

## Structure
- `logo/`: editable SVG wordmark and logo mark, PNG favicons
- `icons/`: lightweight currentColor SVG icons for navigation, contact details, and benefits
- `images/hero/`: hero banner
- `images/categories/`: category cards
- `images/products/`: featured product thumbnails
- `images/banners/`: occasion promo and benefits strip
- `images/store/`: storefront and map-style visual
- `images/backgrounds/`: section backgrounds

## Suggested usage
- Header logo: `logo/logo.svg` (dark/navy header)
- Browser icon: `logo/favicon-32.png`
- Hero: `images/hero/hero-banner.jpg`
- Category cards: `images/categories/category-toys.jpg`, `category-electronics.jpg`, `category-gifts.jpg`
- Featured products: `images/products/product-1.jpg` through `product-5.jpg`
- Occasion CTA: `images/banners/banner-occasions.jpg`
- Benefits section: `images/banners/banner-features.jpg`
- Store/contact section: `images/store/store-front.jpg` and `store-map.jpg`

## Notes for Cursor
Use these files as starter visuals and keep the layout responsive. Icons are SVG and inherit `currentColor`, so set their color with CSS. The supplied map image is illustrative, not a live map; replace it with an embedded map or a real map provider before launch. Product imagery and any details visible in the visual preview are placeholders; confirm product photos, prices, brand usage, opening hours, and contact details before publishing.
